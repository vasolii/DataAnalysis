This project analyzes the Seoul Bike Sharing Demand dataset using statistical methods and predictive modeling in MATLAB. The dataset contains hourly records of bike rentals along with weather and seasonal information. The study investigates seasonal and hourly usage patterns, evaluates correlations with meteorological factors (e.g., temperature, humidity), and applies regression models (linear and non-linear) to explain and predict demand. The exercises cover probability distribution fitting, hypothesis testing, correlation analysis, bootstrap confidence intervals, and regression modeling, providing a comprehensive statistical exploration of bike rental behavior under different conditions.
